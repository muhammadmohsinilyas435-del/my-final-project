# Simple Interest Calculator

## Project Name
Simple Interest Calculator

## Description
A simple program that calculates the **simple interest** on a principal amount
over a given time period at a specified annual interest rate.

## Formula
Simple Interest (SI) = (P × R × T) / 100

Where:
- P = Principal amount
- R = Annual interest rate (in %)
- T = Time period (in years)

## Example
If P = 1000, R = 5, T = 2:
SI = (1000 × 5 × 2) / 100 = 100
Total Amount = P + SI = 1100

## Features
- Takes principal, rate, and time as input
- Calculates simple interest
- Displays the total amount
